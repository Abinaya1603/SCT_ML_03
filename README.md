# 🐾 Cats vs Dogs Image Classification using SVM

## 📘 Project Overview
This project implements a **Support Vector Machine (SVM)** classifier to distinguish between images of **cats** and **dogs** from the **Kaggle Cats vs Dogs dataset**.  
The system processes image data, extracts pixel-level features, and trains an SVM model to predict whether a given image contains a cat or a dog.

## 🧠 Objective
The goal of this project is to develop a supervised machine learning model that can classify images of cats and dogs with high accuracy using basic image features.

## 🧩 Features
- Loads and preprocesses real-world image data  
- Converts images to grayscale and resizes them for uniform feature extraction  
- Uses **Support Vector Machine (SVM)** from `scikit-learn` for classification  
- Splits data into training and testing sets  
- Evaluates model performance using accuracy and classification report  
- Displays sample predictions for verification
